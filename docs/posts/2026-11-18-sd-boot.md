# Booting Pocket from a fresh SD installation

18 November 2026

The laptop installer prepared an SD card with two OS slots and a persistent data partition. The third N810 booted Pocket from that installation. A single flashed kernel serves both the SD system and internal recovery. This removed the second kernel handoff that had left the display blank during earlier tests.

The distinction matters for updates. Selecting a new OS slot changes the root filesystem while retaining the data partition. The fresh boot established that the installer could bring up Pocket. Later application changes were tested on the running tablet. Booting the final image on hardware remains a separate check.
