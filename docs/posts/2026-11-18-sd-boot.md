# Booting Pocket from a fresh SD installation

18 November 2026

The first useful clue on the third tablet was how quickly the installer started after the SD adapter was replaced. With the first adapter, the kernel printed `error -110 whilst initialising SD card`. With the same card in the replacement adapter, the installer came up promptly. That narrowed this particular delay to the card connection. An earlier blank display on the second tablet had taken us down a different path.

## Why keep one kernel running?

The original plan was to boot internal recovery and use `kexec` to start a kernel from the selected SD slot. We had used that technique for kernel development on the original tablet. On the second tablet, recovery reached a visible login, brought up networking, and announced the SD handoff. Then the screen went blank. One diagnostic kernel could still be reached over USB with its display blank. A lit panel or blinking LED alone couldn't tell us which system was running.

We already had a kernel that could drive the console, see the card and bring up USB. What the installer needed to select was the operating system. Early startup now gives the configured card up to 120 seconds to appear, reads the slot selection, mounts that root and its persistent directories, then starts services there. The same kernel runs through the handoff. Each slot carries modules built for that kernel, including the graphics driver. With the card absent, internal recovery provides a console and USB access.

## What the laptop actually wrote

Pocket Setup first wrote the card and read it back. The card holds boot selection on partition 1, OS A and B on partitions 2 and 3, and persistent data on partition 4. The laptop then loaded a temporary installer kernel into the tablet's RAM. Running from the card let the installer identify the internal storage, write recovery there and verify the bytes. Only then did Setup ask for Nokia update mode again to flash the shared kernel.

On the third N810, the first normal boot selected slot A. The root filesystem was read-only, and both `/home` and `/data` came from the card. After touch calibration, Pocket appeared on the LCD. Opening Station Map confirmed that the installed application could find a map and the elevation data. Its first detail view took time to prepare, a separate problem from booting the system.

The [second-tablet investigation](2026-11-17-pocket-on-the-second-n810.md) records the keyboard, audio and graphics work behind this test. The next installation check is to boot the newer kit, create a file in the persistent home, update the other slot, and verify the same file after selecting it and rolling back.
