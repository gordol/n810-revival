# Tracing the installation on the original N810

*11–17 November 2026.*

The first N810 had a copy of Pocket in `/usr/local/share/n810-pocket` and another in `/home/nokia/pocket/current`. The home directory also held experimental Mesa libraries from our GPU tests. To find the graphics release for the second tablet, we followed the launcher in a read-only backup of the first. It selected `/usr/local/lib/n810-graphics/releases/20261109-6970068`, which identified the Mesa library and kernel module we needed to check.

The original tablet had 427 Debian packages and the November 12 installer image had 198. Among packages present in both, only `libutempter0` differed in version. The agent inspecting the backup traced the startup of the APRS receiver (the service that collects station reports over amateur radio). At boot, `/etc/rc.local` called `run-parts /etc/boot.d`, where `85-n810-aprs-feed` started a supervisor as root. The supervisor ran `/home/nokia/n810-aprs-feed.py` as the user `nokia`, and the receiver imported Python modules installed alongside the script.

## The keyboard controller

The original tablet kept its kernel in flash, outside the filesystems we had backed up. When the second tablet's keyboard failed, we rebuilt the original kernel from its source with the original compiler and changed the root-device selection for the new installation. After boot we verified the running build against `/sys/kernel/notes`. With that kernel the LM8323 keyboard controller still failed to acknowledge reads over I²C, and its interrupt count stayed at zero.

## Two Debian roots on one SD card

The second tablet boots either of two Debian root filesystems (slots A and B) with one flashed kernel. Maps live on a separate partition so they remain available from either slot. On November 17 we tried the [audio and graphics repair](2026-11-17-pocket-on-the-second-n810.md) on B and marked the slot good after Pocket started and passed its GPU check. We then booted the repaired A slot and compared the hashes of its audio and launcher files with those on the inactive B partition.
