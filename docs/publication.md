# Publication boundary

This repository is private. Its first source tree excludes personal data,
credentials, device images, firmware, backups, raw radio logs, and private
engineering records. The Pocket import also excludes prepared regional map
data and local history.

The local check looks for common secret forms, machine-specific home paths,
blocked payload types, and unreviewed site media. It cannot prove that every
possible identifier is absent. Each later source or media addition needs a
staged-diff review. No GitHub Pages deployment workflow is present.

Project and third-party licensing still need review before public source
distribution. A private source repository is not a public release.
